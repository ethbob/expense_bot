# Бот учёта расходов из криптокошелька (USDT BEP-20)

Следит за исходящими переводами USDT в сети BNB Smart Chain с одного адреса и ведёт учёт расходов в Telegram.

## Что умеет

- При каждом исходящем переводе присылает уведомление: сумма, адрес получателя, время, ссылка на BscScan, кнопки «✅ Да, расход / ❌ Нет».
- Неразобранные транзакции остаются в статусе ⏳. Если они висят больше суток, бот напоминает (раз в сутки, с 10:00 до 22:00 МСК).
- **📊 Этот месяц** — итог с 1-го числа, стрелками можно листать прошлые месяцы.
- **📋 Транзакции** — список по месяцам. В карточке транзакции можно поменять статус, добавить примечание, удалить.
- **➕ Добавить расход** — неучтённый расход: сумма и необязательный комментарий.
- **⏳ Неразобранные** — всё, что ещё ждёт ответа.
- **📈 За период** — скользящие 30 / 60 / 90 / 180 дней: сумма, разбивка, среднее.
- **📤 Экспорт** — Excel за месяц, полгода или всё время.
- 1-го числа присылает итоги прошлого месяца.

Бот отвечает только владельцу (`OWNER_ID`), остальных игнорирует. Для работы нужен только **публичный** адрес кошелька: приватных ключей и seed-фразы бот не видит.

Учёт начинается с момента первого запуска, история не подтягивается.

## Деплой на Railway

1. **Создай бота.** В Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` → сохрани токен.
2. **Узнай свой Telegram ID.** Напиши [@userinfobot](https://t.me/userinfobot), он пришлёт число.
3. **Залей код на GitHub** (приватный репозиторий).
4. **Railway → New Project → Deploy from GitHub repo** → выбери репозиторий.
5. **Добавь базу:** в проекте нажми **+ New → Database → PostgreSQL**.
6. **Переменные сервиса бота** (вкладка *Variables*):
   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `OWNER_ID` | твой Telegram ID |
   | `WALLET_ADDRESS` | адрес кошелька `0x…` |
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` (ссылка на базу из шага 5) |
7. Railway сам соберёт и запустит бота (`python -m bot`, задано в `railway.json`). Публичный домен не нужен.
8. Открой бота в Telegram → `/start`.

Держи **одну** реплику сервиса: два экземпляра бота с одним токеном будут конфликтовать.

## Как это работает

Бот раз в 30 секунд читает события `Transfer` контракта USDT (`0x55d398326f99059fF775485246999027B3197955`) с отправителем = твой адрес. Данные идут через публичные RPC-узлы BNB Chain, ключи API не нужны. Если узел недоступен, бот переключается на следующий.

Отфильтровываются:
- переводы самому себе;
- переводы меньше 0.01 USDT. Это защита от спама «address poisoning», когда мошенники генерируют нулевые переводы с твоего адреса, чтобы подсунуть похожий адрес в историю.

Комиссия сети (BNB) не учитывается.

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполни значения
export $(grep -v '^#' .env | xargs)
python -m bot
```

## Структура

```
bot/
  __main__.py   запуск, доступ только для владельца
  config.py     переменные окружения
  chain.py      чтение переводов из BNB Chain
  db.py         PostgreSQL
  tasks.py      сканер, напоминания, итоги месяца
  handlers.py   кнопки и диалоги
  keyboards.py  клавиатуры
  reports.py    тексты отчётов и Excel
```
